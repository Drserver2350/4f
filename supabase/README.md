# اتصال دیتابیس مشترک (Supabase — رایگان)

بدون دیتابیس، حساب‌ها و نظرها فقط روی مرورگر همان کاربر ذخیره می‌شوند.
برای این‌که همه نظرهای همدیگر را ببینند و حساب مشترک باشد:

1. در [supabase.com](https://supabase.com) با ایمیل یا GitHub یک پروژهٔ رایگان بساز.
2. از منوی **SQL Editor** محتوای فایل `supabase/schema.sql` را اجرا کن (یک بار).
3. از **Project Settings → API** این دو مقدار را بردار:
   - `Project URL` (مثلاً `https://abcd.supabase.co`)
   - `anon public` key
4. وارد سایت شو با حساب مدیر (`Xray_Venom`)، پنل مدیریت → تب **انتشار فایل** → بخش «اتصال دیتابیس»، مقادیر را بگذار و «ذخیره و انتشار» را بزن.

بعد از این کار، فایل `assets/js/config.js` در مخزن به‌روز می‌شود و همهٔ بازدیدکننده‌ها
حساب‌ها و نظرهای مشترک را می‌بینند.

> نکته امنیتی: کلید `anon` عمومی است و در کد سایت قرار می‌گیرد؛ امنیت واقعی با
> Policyهای RLS تعیین می‌شود. این پروژه برای وب‌سایت استاتیک طراحی شده و همهٔ
> قابلیت‌های آن بدون سرور اختصاصی کار می‌کند. برای امنیت بالاتر (مثلاً جلوگیری از
> ارسال اسپم یا جعل نظر) بهتر است یک Netlify/Cloudflare Function هم اضافه شود.
