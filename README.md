# Felani4F — فلانی فور اف

سایت رسمی لیبل صوتی **Felani4F**؛ استاتیک، سریع و آمادهٔ اجرا روی هر هاست ایستا.

## قابلیت‌ها
- پلیر کامل (موج واقعی هر ترک، جست‌وجو، ولوم، مدیا سشن، کلیدهای میانبر)
- **حساب کاربری** (ثبت‌نام / ورود) با ذخیره‌سازی هش‌شدهٔ رمز (PBKDF2-SHA256)
- **نظرهای واقعی و اشتراکی**: هر کاربر نظر می‌دهد و همه می‌بینند
- **شمارش دانلود واقعی** برای هر ترک + مجموع کل
- **پنل مدیریت**: ویرایش ترک‌ها، تغییر کاور و فایل صوتی، انتشار ترک جدید، حذف/بازگردانی، مدیریت کاربران (ارتقا/مسدودسازی)، حذف نظرها، آمار
- تم دارک قرمز/مشکی، تصاویر از Pexels (اعتبار در `credits.html`)
- PWA (نصب روی گوشی + کش آفلاین)، ریسپانسیو کامل، سئوی ساخت‌یافته (Schema.org)

## حساب مدیر
```
username: Xray_Venom
```
رمز فقط به‌صورت هش در کد است (نمیتوان از سورس خواندش). برای تغییر رمز:
```
python3 - <<'PY'
import hashlib
salt='<salt دلخواه>'; pw='<رمز جدید>'
print(hashlib.pbkdf2_hmac('sha256', pw.encode(), salt.encode(), 120000, 32).hex())
PY
```
سپس `salt` و `hash` را در `assets/js/api.js` (بخش `ADMIN`) جایگزین کن.

## ذخیره‌سازی داده‌ها — دو حالت
| حالت | نظرها و حساب‌ها | مناسب برای |
|---|---|---|
| پیش‌فرض (بدون تنظیم) | فقط روی مرورگر همان کاربر | دمو و استفادهٔ شخصی |
| **Supabase** (رایگان) | **مشترک برای همه** | سایت واقعی |

برای فعال‌کردن حالت مشترک، فایل [`supabase/README.md`](supabase/README.md) را بخوان؛ کل مسیر ۵ دقیقه است.
پس از اتصال، دکمهٔ «ذخیره و انتشار» در پنل مدیریت، فایل `assets/js/config.js` را در مخزن به‌روز می‌کند.

## انتشار تغییرات محتوا بدون دیتابیس
در پنل مدیریت → تب «انتشار فایل» → دکمهٔ «انتشار تغییرات ترک‌ها». این کار فایل
`assets/js/overrides.js` را می‌سازد و تغییرات (نام، کاور، ترک جدید و …) برای همهٔ بازدیدکننده‌ها دیده می‌شود.

## بارگذاری فایل صوتی/کاور
برای آپلود مستقیم MP3 و کاور به مخزن، یک **توکن fine-grained** با دسترسی
`Contents: Read and write` روی همین مخزن بساز و در تب «انتشار فایل» ذخیره کن. توکن فقط در مرورگر خودت می‌ماند.

## افزودن ترک به روش دستی
۱. MP3 در `assets/audio/` و کاور در `assets/img/` (نسخهٔ ۸۸۰px و `-sm` ۱۶۰px)
۲. آبجکت جدید در `assets/js/data.js` (الگوی موجود را کپی کن)
۳. اگر فایل `overrides.js` وجود دارد، ترتیب ادغام: دیتابیس ← `overrides.js` ← `data.js`

## ساختار
```
index.html              صفحهٔ اصلی + سئو
credits.html            اعتبار تصاویر
assets/css/style.css    دیزاین‌سیستم (تم قرمز/مشکی)
assets/js/config.js     اتصال دیتابیس (Supabase)
assets/js/overrides.js  محتوای منتشرشده توسط مدیر
assets/js/data.js       ترک‌های پایه
assets/js/api.js        لایهٔ داده، حساب کاربری، مجوزها
assets/js/app.js        پلیر، UI، پنل مدیریت
supabase/schema.sql     اسکیمای دیتابیس مشترک
robots.txt · sitemap.xml · manifest.webmanifest · sw.js
```
