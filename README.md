# 4F — چهار فرکانس، یک امضا

سایت رسمی لیبل صوتی **۴F**. ساخته‌شده به‌صورت استاتیک برای اجرا روی **GitHub Pages**:
بدون سرور، بدون بیلد، فقط HTML/CSS/JS.

## چه چیزهایی دارد
- پلیر کامل با پخش هم‌زمان، نمودار موج واقعی هر ترک، جست‌وجوی صدا و کنترل بلندی
- کتابخانه‌ی ترک‌ها با فیلتر ژانر، پسندیدن، دانلود و شمارش دانلود
- پنل جزئیات هر ترک (Drawer) با کاور، تمپو، گام و فرم نظر
- بخش نظرها با امتیاز ستاره‌ای (ذخیره در `localStorage` مرورگر)
- دانلود پک کامل (همه‌ی ترک‌ها یک‌جا)
- طراحی ریسپانسیو + منوی موبایل + PWA (نصب روی گوشی و حالت آفلاین)
- پنل مدیریت سبک (`پنل مدیریت` در فوتر): تغییر نام/شعار/رنگ، خروجی JSON نظرها

## اجرا
فایل `index.html` را باز کن، یا:

```bash
python3 -m http.server 8000
```

## افزودن ترک جدید
۱. فایل MP3 را در `assets/audio/` بگذار (مثلاً `my-track.mp3`)
۲. کاور مربعی را در `assets/img/` بگذار (`my-track.jpg` و `my-track-sm.jpg`)
۳. در `assets/js/data.js` یک آبجکت اضافه کن:

```js
const TRACKS = [
  {
    id: 'my-track',        // نام فایل MP3
    fa: 'نام فارسی', en: 'English Name',
    num: '06', genre: 'ژانر', tags: ['...'],
    bpm: 100, key: 'A min', year: '۲۰۲۶',
    c: '#c8ff3d',          // رنگ اختصاصی ترک
    likes: 0, dls: 0, size: 3.2,
    dur: 132,              // ثانیه
    peaks: [0.2, 0.5, ...] // ۲۲۰ عدد بین ۰ تا ۱ برای نمودار موج
  },
];
```

> نمودار موج بدون کتابخانه‌ی اضافه رسم می‌شود؛ می‌توانی `peaks` را با هر ابزاری (مثل ffmpeg + اسکریپت پایتون) بسازی.

## انتشار روی GitHub Pages
```bash
git add . && git commit -m "4F site" && git push
```
سپس در Settings → Pages شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کن.
فایل `.nojekyll` از قبل ساخته شده تا فایل‌ها بدون مشکل سرو شوند.

## ساختار
```
index.html            صفحه‌ی اصلی
assets/css/style.css  دیزاین سیستم
assets/js/data.js     داده‌ی ترک‌ها (اینجا ویرایش کن)
assets/js/app.js      پلیر، نظرها، موشن، پنل
assets/audio/*.mp3    ترک‌ها
assets/img/*          کاورها و آیکون‌ها
assets/fonts/*        فونت‌های وزیرمتن و Unbounded (لوکال)
sw.js                 سرویس‌ورکر (آفلاین)
manifest.webmanifest  تنظیمات PWA
```
